# 🧠 Brain MRI Analysis using Deep Learning

## 📌 Project Overview
This project focuses on analyzing Brain MRI images using Deep Learning techniques to detect abnormalities such as tumors.

The model classifies MRI images into different categories (e.g., tumor / no tumor or tumor types) using Convolutional Neural Networks (CNN).
